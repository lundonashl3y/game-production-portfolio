## Project Overview
Toy Around is an open-world toy car adventure where players explore a child's bedroom, complete objectives, collect items, discover secrets, and unlock new areas through environmental progression.
https://num47.itch.io/toy-around

---

## Project Objectives

- Improve gameplay progression and player guidance.
- Resolve gameplay bugs affecting objectives and collectibles.
- Expand exploration through new traversal mechanics.
- Polish the overall player experience with UI and audio improvements.

---

## Production Challenges

During development, several gameplay systems required refinement to improve player experience and progression.

Key challenges included:
- Collectible tracking inconsistencies.
- Objective completion bugs.
- Lack of visual guidance for interactable objects.
- Limited vertical exploration within the map.
- Missing audio feedback for interactive gameplay elements.

---

## Project Deliverables

### Gameplay Improvements
- Fixed collectible tracking and task progression.
- Resolved the **"E.T. Gone Home"** objective bug.
- Improved overall gameplay stability.

### User Experience
- Added in-world UI icons for:
  - Objectives
  - Points of Interest
  - Interactive objects
- Implemented additional audio feedback for interactable objects.

### New Features
- Designed and implemented a teleporter system.
- Teleporters unlock after completing the **E.T. Gone Home** task.
- Unlock state persists across play sessions until save data is reset.
- Expanded player exploration by providing access to previously unreachable areas.

---

## Responsibilities

As Project Manager, I:

- Planned development milestones and feature priorities.
- Managed the production roadmap for gameplay improvements.
- Prioritized bug fixes alongside new feature development.
- Organized production updates and tracked implementation progress.
- Coordinated testing and gameplay iteration before release.
- Oversaw the project's release on itch.io.

---

## Production Highlights

- Successfully shipped an indie game on itch.io.
- Balanced live bug fixes with new feature development.
- Improved player navigation through environmental UI design.
- Enhanced exploration by introducing progression-based traversal mechanics.
- Delivered multiple gameplay updates while maintaining project scope.

## Project Overview

Culinary Caverns is a 2D pixel art adventure game where players explore a mythical underground cavern filled with food to save a medieval village suffering from a food shortage. Using a fork and spoon as mining tools, players gather resources, complete village requests, uncover hidden areas, and restore the village through exploration and progression.
https://tylerheckel2.itch.io/culinary-caverns

## Project Goals

- Deliver a polished 2D pixel art adventure.
- Coordinate development across programming, art, animation, audio, and design.
- Maintain a consistent visual style and gameplay experience.
