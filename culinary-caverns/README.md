## Project Overview

Culinary Caverns is a 2D pixel art adventure game where players explore a mythical cavern filled with various types of food to save a medieval village suffering from a food shortage.

Using a fork and spoon as mining tools, players navigate through the cavern, collect resources, complete village requests, discover hidden areas, and help restore the village.

## Production Challenges

Culinary Caverns required coordination between multiple creative and technical disciplines to create a cohesive gameplay experience within a limited development timeline.

Key production challenges included:

- Coordinating asset creation between programming and art teams.
- Maintaining consistency within the game's pixel art style.
- Balancing gameplay progression and level design.
- Managing feature implementation alongside bug fixes and polish.
- Ensuring communication between development disciplines remained consistent.
