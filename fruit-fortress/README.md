## Project Overview

Fruit Fortress is a tower defense game where players defend Melon Manor from an army of insect invaders using powerful fruit-themed defenses.

Players must strategically place defenses, protect the fortress, and survive waves of enemies threatening to destroy the sweetest sanctuary.

**Play the Game**

https://amethystaisha.itch.io/fruit-fortress

## Production Challenges

Fruit Fortress required coordination across a large multidisciplinary team consisting of programmers, artists, audio contributors, and designers.

Key production challenges included:

- Coordinating communication between multiple development disciplines.

- Supporting feature integration while working within production deadlines.
