## Project Overview

Toy Around is an open-world toy car adventure where players explore a child's bedroom, complete objectives, collect items, discover secrets, and unlock new areas through environmental progression.

The project focused on improving player exploration, gameplay progression, and overall experience through continued development and feature updates.

**Play the Game**

https://num47.itch.io/toy-around

## Production Challenges

Toy Around required balancing gameplay improvements, bug fixes, and new feature development while maintaining the existing player experience.

Key production challenges included:

- Improving collectible tracking and task progression.
- Resolving objective completion issues.
- Providing clearer guidance for player interactions.
- Expanding exploration opportunities within the game environment.
- Implementing new gameplay features while maintaining project scope.
